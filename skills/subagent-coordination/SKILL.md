# 子 Agent 派发与协调

接收所需职责、目标/阶段、有效输入与版本、候选、写入边界和独立性要求。先核验宿主真实能力和本次用户/模型约束；角色配置存在不证明可以原生派发。

建立最小充分任务包；共享文件及服务明确唯一负责人。依据依赖与写入隔离决定并发；作者与独立评审实例分离。派发后使用宿主等待能力并继续独立工作，超时不等于任务结束。模型/推理由本次策略决定，不固化为 Skill 默认。

核验返回的真实文件、版本和执行方式，交由相应职责判断专业结论，由主 Agent 综合流程完成。返回结果不能自动视作评审通过；不承担 Git 合并。无法委派记录降级和独立性缺口。
