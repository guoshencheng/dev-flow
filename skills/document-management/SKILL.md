# 项目文档管理

先定位用户所指项目和已有权威索引，接收专业职责提供的有效内容/结论。按当前项目约定维护，不从目录日期或现有实现自行判定业务规则有效。

迭代整体收尾由 [iteration-closeout](../iteration-closeout/SKILL.md)组织资料盘点、专业核对与实际回写，本 Skill 承接具体文件组织、现行正文更新、索引与归档；单独文档整理不因此扩大为完整迭代收尾。

按需要执行目录/模板落位、引用更新、预览、总结保存或归档。通用组织规则只维护一份，专业内容与有效性由所属职责负责；总体阶段和证据失效语义由流程负责。总结引用原记录，不补造确认或验收。

文档编写后的自查和 Review 使用 [document-review](../document-review/SKILL.md)。本 Skill 只维护目录、索引、权威来源及预览机制，不另行定义评审步骤和结论格式。

交接源文件与版本、索引/替代关系、已组织范围与断链/待决；需要阅读入口时再提供核验后的真实 Web URL。文档归档不等于迭代完成，不自动删除历史、改代码或创建调度。
