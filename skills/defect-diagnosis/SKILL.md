# 缺陷根因诊断

核对问题现象、有效预期、候选、环境、数据和原证据；不能将描述或重试次数当成根因。优先沿用已有缺陷记录。

在相同条件复现并寻找正常对照，提出可反驳假设，用最少变量实验定位边界与原因。分清实现、测试及环境问题，依据真实原因提出最小修复和受影响回归。

交接根因证据、最小复现、影响范围、建议与未知。研发承担修复，测试复验原问题；普通评审意见的专业裁定和关闭不由诊断动作代替。
