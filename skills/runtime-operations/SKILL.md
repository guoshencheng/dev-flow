# 环境与运行操作

定位真实工程、配置来源、依赖、端口/数据和候选身份，复用已有 runbook；仅可访问某端口不能证明它是当前项目。

按项目命令启动并核验真实服务/版本，检查进程、技术健康和业务结果各类信号；排除环境问题并保留诊断。只停止明确归属且不再需要的服务，用户仍需预览时保留入口。

返回实际版本/环境、入口、启动停止方法、检查和未知项。需要发布或数据/应用恢复时转发布恢复方法，业务验收交测试。
