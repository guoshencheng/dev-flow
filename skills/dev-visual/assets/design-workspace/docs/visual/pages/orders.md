# 订单页面规格（候选示例）

页面 ID：`orders`。目标：查看、搜索订单和读取详情。数据、状态与规则仅为虚构示例，采用前由项目产品规则替换。布局与组件的设计基准引用 [设计规范](../system.md)。

| 展示端 | 现行源码 | 入口与组合 |
| --- | --- | --- |
| 桌面 Web | `src/features/orders/views/DesktopOrderPage.tsx` | 总览 iframe 与 `#/page/orders-desktop` 引用同一视图 |
| 移动 Web | `src/features/orders/views/MobileOrderPage.tsx` | 总览屏幕容器与 `#/page/orders-mobile` 引用同一视图 |

共享状态标签、详情与内容状态在 `components/` 中维护；摘要契约见 [订单摘要](../components/order-summary.md)。每个视图单独持有输入、筛选和选中订单，场景切换重新创建该实例，不共享可变页面状态。

## 可观察行为

- 正常场景显示示例订单；搜索按订单编号、客户和商品的包含关系匹配，桌面状态筛选及移动待处理分类可组合。
- 点击查看打开当前订单详情，关闭后返回列表；弹层在同一浏览上下文，移动预览不会覆盖总览外部内容。
- 加载场景展示骨架；空场景显示零订单；错误场景显示重新加载，点击后恢复正常示例内容并保留筛选输入。
- 移动内容超过屏幕高度时内部滚动，底部分类固定在内部视口底部。

展示场景使用 `?scenario=normal|loading|empty|error`，位于 hash 路由之后。状态切换属于设计展示，不能证明真实业务可达或 API 已实现。

## 维护方式

现行页面在本文件与对应源码原位更新，候选/确认绑定实际源码版本；普通历史由 Git 追溯。新迭代只记录受影响资产、基线、变化、检查与确认，不重新复制本页面或完整规范。
