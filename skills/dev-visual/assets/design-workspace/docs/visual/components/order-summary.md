# 订单摘要组件

源码：`src/features/orders/components/OrderSummary.tsx`。用于业务页面与组件展示，两个入口引用同一个实现。设计基准见 [设计规范](../system.md)。

| 输入 | 含义 | 边界 |
| --- | --- | --- |
| `orders: Order[]` | 当前示例订单集合 | 组件只读取输入，不调用接口，不修改集合 |

展示订单笔数、`pending` 状态笔数和金额合计。空数组时三项均为零；金额按 CNY 整数示例显示。计数与合计是派生数据，不建立重复 state；真实币种、退款与金额口径由项目规则另行确定。

布局保持三项同级呈现，组件展示提供有内容与零内容两个实例。主题从 `src/theme/tokens.ts` 读取；组件契约、页面规则和总览布局分开维护。组件改变后检查实际页面消费者和展示实例。
