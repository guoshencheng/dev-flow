# 视觉参考与方向

## 从任务和现有资产开始

先核对当前品牌、目标人群与设备、产品信息优先级、实际主题和已有偏好依据。既有有效方向可直接复用；没有品牌输入时提出与任务相符的候选，说明依据，不将个人审美登记为用户要求。

参考研究按问题开展：信息密度、导航与层级、数据展示、关键行动、字体和内容长度、目标窗口或平台特征。B 端先看 Ant Design 官方组件和设计模式；C 端 Web 从项目 shadcn 基底和定位探索；其他 C 端先浏览同类任务及平台规范。实际外部来源需要浏览核验，不能根据记忆编造产品截图或链接。

## 将参考转成可用规则

每份有作用的参考记录来源、观察日期/版本、页面与状态、截图或实际操作方式、可借鉴机制及不适用条件。区分观察与推断，外观相近不证明业务、平台或操作行为相同。

从参考提取具体规则，例如字号层级与阅读宽度、主次色使用、密度与间距、对齐方式、图像与留白比例、关键操作的位置。将候选规则映射到实际 Token、组件或布局实现，在同一任务和内容上比较，避免把多个互不相容的参考装饰拼在一起。

选择范围由重要取舍决定，不强制每次产出固定数量方案。记录采用理由、未采用方案的关键原因和仍需核验项；项目只保存与任务有关的参考。借鉴视觉机制、直接采用源码和使用素材分别记录来源与实际许可。

## 方案和资产

以实际页面、必要状态或可运行原型展示候选；静态图片作为参考或视觉资产，不声称其交互已经成立。若本次确有图像创作或复杂设计文件需要，使用当前可用的专业工具，关联源文件、版本、用途与可预览导出，不将工具安装本身登记为设计能力已验证。

项目视觉方向、参考与有效决定进入视觉索引；跨职责的交互参考可以直接链接已有产品记录，不复制相同来源。参考过期或项目约束改变时核验受影响规则。
