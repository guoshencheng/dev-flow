# 视觉规格内容与权威来源

视觉主责呈现、设计系统、Tokens、组件与实际渲染；产品主责用户任务、透出、交互语义和业务规则。项目目录、状态和归档采用[共同文档协议](../../dev-flow/references/design-document-contract.md)，按本次影响裁剪。

## 规格最低内容

视觉规格引用输入产品版本、相关 RULE/AC、当前设计系统和实际组件。记录布局与信息层级、字体/间距/颜色/尺寸、组件选择、必要状态呈现、目标窗口/内容变化、焦点与相关动效；Tokens 指向实际代码或 ConfigProvider 的权威来源。

关联可预览页面/MDX/原型及对应截图、浏览器/尺寸/数据/状态/源码版本，分别记录已检查和未覆盖内容。只形成方案时标为候选；检查过实际界面才能登记视觉验收。视觉改变若影响可见性、操作流程或业务规则，回到产品规格共同更新。

采用[视觉规格模板](../assets/templates/design-spec.md)，页面与组件方法见[设计系统与页面](system-and-pages.md)，实际检查见[渲染复核](rendered-review.md)。
