# 组件发现与源码接入

读取项目实际组件、栈、目标行为及视觉约束，优先复用已满足要求的实现。UI 默认约定引用视觉维护的唯一基准，实际版本与差异留在项目。

查询随包目录/示例和真实源码，必要时核验官方 API。按 catalog 文件集复制到项目并记录来源哈希、差异和依赖；接入项目主题、类型及构建，避免只复制入口遗漏资源。具体缺口成立后再自建组合。

输出所选组件及依据、复制文件/依赖、来源与定制差异、真实预览和检查结果。组件接入不承担整套视觉方向或业务政策决定。
