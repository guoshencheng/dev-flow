## 阅读与预览

记录采用的文档工具位置、文档根目录与实际启动方法；采用共享阅读器时 `--project` 指向本项目，`--roots` 指向上表实际文档目录。各角色共用此入口，独立原型关联自身服务及场景。

长期记录保存源路径和启动方式。本机 origin/端口从 `.dev-flow/previews/documents.json` 取得，提供给用户前用 URL 工具核验对应项目与文件；不将临时端口作为永久地址。预览变更反馈写回上表对应权威资料。
