# 职责 Skills 与执行者

本插件通过流程 Skill 和六个专业 Skills 提供能力，Codex 不要求注册原生职责 Agent，也不需要 setup。安装、更新与解除见[插件维护指南](../../../docs/plugin.md)。

主 Agent 按[任务路由](task-routing.md)选择产品、视觉、架构、研发、测试或运维方法。专业职责是分工，不自动表示存在独立执行者。标准跨职责任务在用户、项目指引和宿主能力允许时，默认派发专业设计、调查、研发、Review、验收及收尾，主 Agent 管理[全局进度](progress-management.md)、依赖与集成；明确的局部工作可直接执行。

使用宿主实际可用的原生 subagent，提供对应 Skill 的绝对路径、原始要求与权威文件、目标、输入及版本、可写范围、产物位置、验收与交接要求。传递窄上下文任务包，不默认复制整段聊天。模型和推理强度遵循用户及宿主本次约束，不写死在插件中。不能委派时由主 Agent 执行并记录原因；自查与独立 Review 分别表达，缺少要求的独立 Review 时不登记为通过。

各流程的默认安排、并发边界与交接见[subagent 使用建议](subagent-guidance.md)；工作目录、分支和隔离安排见[Git/worktree 建议](git-and-worktree.md)。同一文件只有一个写入者，作者和独立评审者分开；共享分支、端口、数据及发布目标分别指定负责人。只读 Review 不默认建立 worktree，集成后重新验证。派发后主会话继续独立工作或使用宿主等待能力；等待超时和单个子任务完成都不是总体结束。

插件安装检查、专业行为和项目资产复用分别验证。Skill 能被发现不表示已完成某项任务，执行结果必须有对应成果和证据。
