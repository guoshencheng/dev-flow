# Git 与候选操作

明确仓库/工作目录、所需动作、任务开始基线、变更归属及已有授权。先检查当前分支、工作树、暂存区和已有 worktree；保留无关修改。非 Git 项目按约定交接工作副本，不强行初始化。

根据项目策略选择分支或 worktree，取得任务开始至最终候选的完整差异（含相关暂存/未暂存与未跟踪文件）。核对候选、检查结果和暂存范围后保存；合并或冲突修复后检查实际组合。推送、PR、合并及发布副作用只在实际授权内执行。

返回基线、分支/工作区、实际候选/提交或 PR、验证与残余修改、资源保留状态。提交和业务验收分开报告；独立 Git 任务不自动启动完整研发流程。
