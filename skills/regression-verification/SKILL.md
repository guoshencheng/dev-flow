# 目标失败与回归有效性

读取有效预期、目标行为、旧/新候选和已有测试。选择能捕获本次问题的最小检查，区分实现行为、工具/环境失败；低影响文档等按对象裁剪。

适合自动化时先取得目标失败，再核验修复通过；事后补测在隔离旧/新实现运行，不能只凭新实现一次通过。根据影响补相关回归，避免修改预期迁就实现。

返回命令/环境、候选、失败原因与通过证据、保护范围及未测项。未知根因转缺陷诊断；局部测试有效不等于正式验收通过。
