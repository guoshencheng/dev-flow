# 原型构建与预览

读取待表达的产品/视觉设计、实际项目与现有原型工程、场景和模拟边界。优先原位修改，避免每轮复制完整设计工程；原型与生产实现分别记录。

依现有栈复用主题和组件；需要新建时采用随包设计工作台或 Vite React 工程。按页面、组件、主题、场景拆分；多端视图独立，移动端核验内部尺寸。启动真实服务并操作目标路径；业务选择和呈现判断交产品/视觉。

交接源码版本、真实入口、场景/模拟范围和实际操作结果。静态 HTML 源路径不等于可运行 React 应用；原型能点击不证明生产验收通过。
