# 禾一 · 设计规范

这是模板内独立维护的候选规范。项目采用时按品牌与目标任务替换本文件；展示模块直接读取此原文，页面和规范展示同时使用 `src/theme/tokens.ts` 的真实主题。

## 视觉方向

用清楚的层级、留白和稳定的组件表达秩序。绿色表示主要行动与当前选择，正文保持深色，辅助内容减少干扰。色彩与数值以主题模块为准，本文件不维护第二份 Token 表。

## 字体与间距

字体使用系统字体栈，保留中文与数字可读性。标题、正文和辅助文字采用主题中的语义字号；间距遵循主题节奏。组件内部紧凑，业务区域之间留出阅读空间；长文本自然换行，不遮挡状态与操作。

## 组件与状态

基础控件直接使用 antd，领域组合按需维护在 `features/orders/components/`。状态颜色同时配合文字；空内容、加载、失败和成功的含义分别表达。按钮保留焦点与键盘行为，错误给出恢复入口。

## 多端布局

桌面页面使用侧栏、摘要和表格，移动页面使用单列订单卡片与底部分类入口。它们独立组合，相同领域标签/详情引用同一组件。总览仅整合显示，不成为页面或规范的另一权威来源。

## 移动端屏幕范围

尺寸单位为 CSS 像素，外壳在实际屏幕区域外。内容、内部滚动、固定导航和弹层由 iframe 内部页面呈现。外部缩放只调整展示比例，屏幕内部仍保持指定宽高；不模拟手势、键盘、设备 API 或操作系统。
