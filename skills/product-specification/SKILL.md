# 产品规格表达

读取原始任务、有效决定和接口/业务约束，区分事实、确认、候选与未知。产品负责价值取舍及业务语义，本 Skill 将它们表达为可执行规格；未知不编造默认。

默认以功能和用户任务组织正文，先说明有哪些功能、谁使用、从哪里进入、如何操作及得到什么结果；字段、权限、计算、边界和异常恢复归属具体功能及步骤。小功能可几段表达，大功能按任务分节，不强制相同小标题或表格，不以全局 RULE/AC 表作为阅读主线。状态写明触发、用户操作、反馈与退出。需要研究来源时按需读参考研究方法；现有有效规则直接复用。

使用功能规格模板的内容提示输出可读规格、就近验收示例、来源和未决项；流程/状态表按需采用。已有稳定编号保留，新编号按需采用，通过附录定位正文，正文无需查编号即可理解。AC 是业务可观察预期，不替代测试 TC；写出规格不代表用户已确认或实施获授权。
