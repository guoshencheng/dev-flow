# 产品规格表达

读取原始任务、有效决定和接口/业务约束，区分事实、确认、候选与未知。产品负责价值取舍及业务语义，本 Skill 将它们表达为可执行规格；未知不编造默认。

按本次影响组织入口/成功结果、正常及拒绝/恢复分支、状态/透出、字段/权限/边界及 RULE/AC 映射。状态写明触发、用户操作、反馈与退出。需要研究来源时按需读参考研究方法；现有有效规则直接复用。

输出规格、流程/状态表、稳定 RULE/AC、来源和未决项，必要时使用功能规格模板。AC 是业务可观察预期，不替代测试 TC；写出规格不代表用户已确认或实施获授权。
