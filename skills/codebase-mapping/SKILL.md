# 代码业务链与模块地图

从实际项目、范围与代码候选定位路由/命令、配置、schema 和测试；区分既有事实与设计目标，排除依赖/构建噪声。

沿入口→授权/校验→用例/规则→端口适配→数据与结果追踪。记录模块职责、数据所有权、公开边界、目录/符号、调用与依赖，动态边未解析则标未知。

产出带源码版本、覆盖范围和证据的地图与未知区域。目录树和 import 清单仅是线索，地图生成成功不等于架构合理；专业结论由架构依据其规范判断。
