# 实际呈现检查

核验候选源码/服务、有效 UI 规格、目标设备/窗口、主题、内容与状态；不能把旧截图当当前版本证据。

选能回答本次问题的页面和状态，在真实浏览器检查层级、排版、溢出、组件/弹层边界和焦点反馈。移动尺寸容器记录内部视口与缩放；定位具体问题后在修复候选复验。

返回条件可复现的截图/观察、问题位置、实际覆盖及未覆盖。构建通过不证明呈现通过；视觉证据不能替代产品流程、真实设备兼容或业务 E2E。
