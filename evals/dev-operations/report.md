- 从既有纯源码样本与已验证补丁重建固定实现，生成 good/bad 两个可分发源码包，实际解包到另一目录；归档含源码、版本/摘要与启动说明，没有依赖源码候选目录运行。
- 使用本机 Node，缺少必需配置时实际启动失败，错误可定位；完整配置启动后核对产物身份与运行源码摘要，实际登录/保存/读回，拒绝越权与空输入且无副作用。
- 正常停止后入口关闭；另一进程启动仍能读回原数据。故障包健康返回 200、保存返回 201，真实读回缺失，业务探针判定失败。
- 回退到原 good 包后已有数据保留，新的保存/读回恢复。全部写入进程停止后复制一致文件备份，隔离数据丢失可观察；恢复到另一文件后完整快照相符，并能继续写入/读回。
- 六个样本进程均已停止且对应端口关闭。本地包/数据/日志留在忽略工作副本，持久结果保留必要脱敏证据；源码与执行配方在 Git 可重建。
