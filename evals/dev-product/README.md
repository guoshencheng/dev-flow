## 原生派发尝试

隔离项目先安装同一职责配置，再通过 CLI 0.156.1 启动 Sol medium 父任务，要求只派发原生 `dev_product` 并等待返回。CLI 回退到 HTTP 后返回模型不受当前 ChatGPT 账号通道支持，退出码 1，父任务未开始推理。错误节选见[原始错误记录](runs/2026-10-07/native-cli-attempt.json)。

这个错误不能证明 TOML 角色格式有问题，也不能证明目标宿主已经发现角色。全局链接和静态检查只证明配置存在。后续在目标宿主使用实际选择的模型验证角色发现、派发及模型/强度，并另存对应执行证据；模型改变不改写本次历史结果。
