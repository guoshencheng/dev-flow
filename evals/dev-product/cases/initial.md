# 隔离案例一：模板批量导入的交互设计

这是虚构测试项目，所有业务数据均为测试数据。用户请求：为已有桌面 Web 模板管理台增加 CSV 批量导入，完成产品与交互设计和可验收场景，供视觉、架构、研发和测试继续。不要实现生产代码或创建部署。

已确认要求：

- 目标用户为有编辑权限的模板管理员，入口是现有“模板列表”；目标是导入后在列表看到新增模板。
- CSV 使用 UTF-8，字段为必填 `name`、必填 `category`、可选 `note`。名称去掉首尾空白后非空，并在当前项目中区分大小写地唯一；同一文件名称重复的所有相关行都是错误行。
- category 必须为当前项目的已有分类。空文件或没有有效行不能提交；超过一千行不能导入。
- 先解析并预览，显示有效及错误行。用户明确提交全部有效行，错误行不提交且可下载错误清单。
- 提交前可取消并重新选择文件。提交后不能撤销后台任务；关闭页面只停止等待。
- 不增加自动导入、跨设备草稿恢复或新分类管理。

项目中 `contracts/import.md` 是版本化权威接口，`docs/product.md` 是已有产品入口。仅在 `docs/` 下维护本次文档，保持 `src/` 与接口文件不变。项目没有运行中的应用、浏览器会话或真实用户，提交设计的验证范围应与此一致。

请直接完成可行的设计、场景和项目入口更新，记录实际来源、复用与变化、下游依赖和未执行验证。不要把你想到的设计建议称为用户已确认。
