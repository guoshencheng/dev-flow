# 导入接口契约

版本：0.3。权威来源，模拟项目规格，未提供可运行接口。

CSV 最大行数：1000。
管理员提交有效记录与 client_batch_key，服务端按该标识保证同一批次只创建一次。
提交响应返回 job_id。可按 client_batch_key 查询是否已接收，以及按 job_id 查询 running/succeeded/failed 状态与实际成功、错误数量。
网络超时不代表未接收；必须查询同一批次再决定下一步。同一标识携带不同内容时拒绝。
提交后不提供撤销；关闭页面只停止前端等待，后续可在导入记录查看状态。
分类和模板名称由当前项目数据提供；导入时重新验证权限和数据约束。
