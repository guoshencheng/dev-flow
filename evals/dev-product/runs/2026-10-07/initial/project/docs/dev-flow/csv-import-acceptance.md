# CSV 批量导入验收场景

版本：0.1。状态：规格和纸面走查已完成；以下全部应用与接口场景尚未实际执行。权威语义见 [交互规格](csv-import.md)，原有 AC-EDIT-01 保留在 [入口](../product.md)。

代表测试条件：隔离当前项目，分类 `办公`、`展示`，已有名称 `Desk`；编辑用户 E、无编辑权限用户 V。均为本次构造的测试数据，不是读取的真实业务数据。CSV 表头为 `name,category,note`。服务端响应、权限变化与网络故障由下游模拟接口或测试环境控制。

| 编号 | 条件及操作 | 可观察结果 / 验证重点 | 规则 / 状态 |
| --- | --- | --- | --- |
| AC-IMPORT-01 | E 在模板列表选择两行 `Chair,办公,说明` 与 `desk,展示,`；预览并点击“导入全部 2 条有效模板”；模拟 succeeded 2 / 0，返回列表 | 预览有效 2；desk 与既有 Desk 不冲突；请求只含这两条及批次键；实际结果 2 / 0；刷新列表看到 Chair 和 desk。实际列表显示为核心成功条件。 | R-01/02/05/07，S0→S8 |
| AC-IMPORT-02 | 文件中 ` A ,办公,`、`A,办公,`、`Desk,办公,`、`B,展示,`；预览 | A 的两条相关行均错误，Desk 与当前项目重名错误，B 有效；统计 4 / 1 / 3；点击导入只发送 B。每条错误有原因。 | R-02/05，S2 |
| AC-IMPORT-03 | 分别选择空文件、仅表头文件、全部错误行文件 | 禁用提交；空文件说明为空，仅表头说明没有数据行，全部错误允许下载错误清单和重选；没有后台导入请求。 | R-01/04，S3 |
| AC-IMPORT-04 | 分别选择 1000 条唯一有效数据和 1001 条数据，其中后一文件有多条错误 | 1000 条可预览提交；1001 条整文件禁止导入，不能仅按有效行数 ≤1000 放行；表头、空白记录、引号换行计数以确认后的解析约定执行。 | R-04，S2/S3；解析待确认 |
| AC-IMPORT-05 | ` ,办公,`、`C,,`、`D,不存在,`、`E,办公,`；另测缺 name/category 表头、重复表头、非 UTF-8、损坏引号 | 前三条行级错误，E 有效且 note 可空；表头或格式错误整文件禁止提交并有具体原因。行级与整文件错误可区分。 | R-01/03，S3；格式细节待确认 |
| AC-IMPORT-06 | 包含中文、逗号和引号 note 的混合文件预览；筛选错误并下载 | 筛选不改变“全部 N 条有效”范围；下载与错误行对应，原值、记录序号、全部原因可追溯；修正并重选后旧统计清空，新预览出现。检查 UTF-8 与 CSV 转义。 | R-05，S2；导出候选 |
| AC-IMPORT-07 | 解析延迟期间重选文件；预览期间取消；再次打开 | 旧解析结果不能覆盖新文件；取消清空未提交内容且无导入请求；重开为未选文件；焦点返回模板列表入口。 | R-06，S0–S3 |
| AC-IMPORT-08 | 预览获取分类 / 名称失败，点击重试 | 无可信数据时不标记有效或允许提交；提示数据加载失败；重试成功才形成预览，不将加载失败当空集合。 | R-03，S1/S3 |
| AC-IMPORT-09 | V 进入列表；E 预览后编辑权限被撤销，随后提交被服务端拒绝 | V 无可用提交操作且说明权限；E 收到明确拒绝、预览保留、禁用提交并无创建；恢复权限后重新校验再提交。接口若已建 job 则按真实任务状态报告，不能伪称未接收。 | R-10，S3/S7 |
| AC-IMPORT-10 | E 连续双击或按 Enter 提交；模拟重复发送同键同内容，再模拟同键异内容 | 前端首次提交立即锁定内容，重复操作不新建批次；服务端同键同内容只创建一次；异内容明确拒绝；用户看到真实原因。 | R-07，S4 |
| AC-IMPORT-11 | 提交响应丢失但服务端已接收；按键查询返回 job_id / running，后 succeeded | 显示未知并保留键；先查原键，恢复任务等待；不产生新键提交；最终显示实际结果并刷新列表，无重复新增。 | R-07/08，S4→S6→S5→S8 |
| AC-IMPORT-12 | 提交超时，查询也不可达；之后权威查询明确未接收，重试 | 不将超时标记失败；未知期间不能盲目提交；明确未接收后使用同键同内容重试，后响应丢失仍能同键查询。具体“未接收”响应形态待架构补齐。 | R-08，S6/S4 |
| AC-IMPORT-13 | job running 时关闭页面，再进入导入记录 | 关闭文案明确后台继续，没有撤销请求；记录重新查询并显示真实状态、数量；未提交文件没有记录。待列表 / 恢复接口实现后才能验证。 | R-06/07，S5；接口依赖 |
| AC-IMPORT-14 | 预览后分类删除或其他用户占用名称；提交时重新校验，任务成功 1 / 错误 1 | 显示实际 1 / 1，不把预览有效 2 当成功数；列表只显示实际新增；不自动重提失败记录，不编造服务端逐行错误清单。 | R-03/09，S8 |
| AC-IMPORT-15 | job failed，服务端报告成功 1 / 错误 1；或数量尚未知 | 失败结果仍显示已有实际成功数；未知数量写尚未确认，不能当 0；不承诺全部撤销。修正文件再预览时已有成功名称会报重名。 | R-09，S7 |
| AC-IMPORT-16 | 使用键盘完成选择、预览筛选、下载、提交、关闭和重开 | 所有操作可达；焦点不会丢到关闭容器或已禁用按钮；加载 / 错误 / 成功文字可被读屏感知；错误不只靠颜色。实际浏览器与读屏待验证。 | 所有相关状态 |
| AC-IMPORT-17 | 导入成功后再次执行原有模板编辑、保存并重开；另测编辑失败 | 原 AC-EDIT-01 仍成立，失败保留输入；新增入口不改变查看和编辑语义。 | 既有回归 |
