## 实际浏览器操作

使用 Codex 内置浏览器与 CUA 操作实际页面，检查可访问性树和实际渲染；不是仅读取 HTML 推断行为。

| 场景 | 实际操作与观察 |
| --- | --- |
| C 端确认方案 | 从预约入口打开模态；选择另一服务与日期，同页确认显示对应输入；返回修改保留输入 |
| 模态键盘 | Tab、Shift+Tab 在确认/返回按钮间循环；Esc 退出，焦点回到原操作按钮；首次检查发现焦点边界问题，补充约束后复验通过 |
| 提交与未知结果 | 确认后显示提交中，不存在重复提交按钮；模拟未知结果提供查询入口，查询进入模拟成功 |
| B 端批量范围 | 未选择时批量按钮禁用；选择两项后确认显示两项的名称和数量，确认阶段禁止改动范围 |
| 失败恢复 | 模拟失败返回后两项选择保留；修复返回焦点后复验，焦点回到批量操作按钮 |
| 模拟成功 | 返回列表后两项显示已发布（模拟），其余仍为待发布；没有将模拟结果称为生产发布 |
| 空与权限 | 直接切换相应展示场景，看到具体说明和返回示例入口；权限场景不出现提交按钮 |
| 反馈与导出 | 以代理走查记录观察，关联 ID、版本、任务、方案、状态和视口；导出后可见有效 JSON，并从该可见内容保存为[浏览器反馈证据](browser-feedback.json) |
| 响应布局 | 默认 456 px 与 390 px 视口的文档宽度等于视口，无页面横向溢出；1280 px 验证桌面三列布局。临时视口设置已恢复 |

## 局限与后续验证

首次导出使用 Blob 下载触发后，内置浏览器没有返回下载事件；页面消息不能证明文件落盘。修订为先展示可复制的 JSON、另提供下载链接。已验证生成内容可解析，并将可见内容保存到本记录；原生 Blob 下载仍未确认，不将辅助复制方式冒充下载成功。

当前原型数据保存在浏览器内存；URL 只保存场景控制，不恢复输入、选择或后台任务。真实项目需要给具体复现场景绑定数据与版本。模拟时间、任务结果和权限不是后端契约。未访问生产应用、真实接口或真实用户，未做生产功能验收。

参考研究、C/B 设计与跨项目模式推广是新增指导，本轮未组织真实竞品任务研究或用户对比。后续以项目任务复验其适用性，保留来源、反例与实际反馈。原生 Agent 的发现与运行时模型继承继续沿用此前未验收状态。
