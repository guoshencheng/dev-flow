# 实施前决定（合成事实）

这些是评测准备者设置的有效前置条件，**不是对真实用户消息或真实外部 Review 的声称**。评测执行者可将它们视为本隔离项目中已经给定的事实；新增业务预期或范围变化仍需辨识，不应倒填成已确认。

| 对象 | 输入与范围 | 合成决定 |
| --- | --- | --- |
| 产品规则和可观察完成标准 | `product/spec.md` v1，RULE-01～06、AC-01～07，CLI 单订单备注范围 | 产品规则、拒绝、恢复和 zipapp 交付结果已于候选形成前确认。 |
| 研发设计 | `engineering/design.md` v1，OUT-01～03 | `engineering/design-review.md` 的独立 Review 已在编码前通过。 |
| 实施计划 | `engineering/plan.md` v1 | 编码前已复核范围、验证和交付。 |
| 实施授权 | 上述 v1 输入；范围仅为本 CLI 功能 | 合成授权语句：“同意按这些规则、设计、计划和交付范围开始实现。”当前候选仍在该范围内。 |

本轮没有正式用例、正式用例 Review、验收执行或交付产物启动记录。产品预期内的用例细化不需要例行再次索要实施许可；如果发现规则冲突或新增行为，应只处理受影响决定。
