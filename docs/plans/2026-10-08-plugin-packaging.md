# 本地 Plugin 实施计划

目标：用户已同意以 Git 仓库维护源码、Plugin 分发 Skills 与资源、初始化接入六职责配置。复用现行流程，不新增业务设计确认或运行内核。

产出：便携与兼容清单、repo marketplace、干净包构建/安装/检查/移除命令、初始化 Skill 与六角色适配、中文安装说明及真实核验记录。

切片：先写清单与初始化，再实现 Git 文件打包和官方 CLI 安装，完成隔离文件系统验证后接入当前用户；最后检查新上下文的插件 Skills 与角色发现。重要未知是当前 CLI 的缓存刷新行为和原生角色发现，使用实际命令取证，不把文档描述当成执行结果。

必需检查：包中没有依赖/运行缓存；角色没有固定模型；旧入口迁移与重复初始化成立；外部占用和自改副本不被覆盖；更新后角色路径/指纹一致；解除保留其他设置；真实插件安装启用、源码与缓存一致；项目文档与组件引用完整。

AI 复核：主 Agent 对照有效要求与实际入口自查。发现原角色固定读取旧全局 Skill 路径、安装缓存不能当作源码链接、依赖目录巨大，已通过生成角色副本、指纹核验/显式刷新和 Git 文件打包落实。没有新增人工计划审批。独立复核和原生角色执行不以本次自查替代。
