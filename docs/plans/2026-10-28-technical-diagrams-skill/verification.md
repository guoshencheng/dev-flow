# 技术图示 Skill 验证记录

## 独立试用及对照

在 `.dev/technical-diagrams-eval/` 的隔离输入上，分别由独立执行者运行有 Skill 和无 Skill 基线。模型均为 gpt-6.1-terra / xhigh；每项各一次，结果只用于发现具体问题，不作为统计有效的能力提升结论。

| 场景 | 预期 | 实际观察 |
| --- | --- | --- |
| 数据库 ER | 根据 SQL 给出三条 FK 的表/字段、可空、联合主键及未声明关联，不编造约束 | Skill 试用覆盖关联与未知，但正文误称四表都有 `id`；反馈后修正，Skill 增加逐表核对实际字段要求。无 Skill 基线也覆盖主要关系 |
| 架构目标 | 区分目标设计的运行、依赖、实现和装配，不编造部署及运行事实 | Skill 试用区分目标与未知；作者在阅读器看到结构图标签重叠，反馈后将装配拆图并复验。无 Skill 基线也覆盖主要关系 |

原试用执行者未进行 Mermaid 渲染；主 Agent 在临时项目的文档阅读器（1280×720）中观察 Skill 试用版 ER 图和架构图，架构结构图的重叠修复后复验，现能区分主要标签，拆分后的装配时序图可读。该检查不证明其他阅读器、数据库实际约束或真实项目行为。

## 独立评审与检查

独立架构评审 `candidate_review`（gpt-6.1-terra / xhigh）检查 Skill 入口、方法和示例，架构职责边界、兼容链接、能力声明及宿主生成；指出旧锚点与旧示例标题、文档中 Skill 数量、以及通用绘图误加架构注入要求。作者修订后由评审者定向复验关闭；范围是静态候选，不涵盖原有插件完整性迭代或实际安装。

Skill 格式校验、宿主入口同步、相关链接/锚点及 `git diff --check` 通过。包含未提交候选与既有未提交工作的隔离 Git 快照可构建插件；不把该快照等同于单独发布候选或已安装产物。插件版本仍沿用工作区原有值，未对本次 Skill 候选升级、安装或发布。
