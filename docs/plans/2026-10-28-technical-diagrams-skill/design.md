# 技术图示 Skill 设计

`technical-diagrams` 是可独立触发、跨职责复用的操作 Skill：输入为用户问题、证据和范围，输出 Mermaid 图、文字关系、依据及实际验证/未知；不启动完整研发流程，不替代用户决策或专业评审。

通用选图、构图、ER 字段映射、源码维护和呈现检查迁入 Skill 的方法参考，示例放入 Skill 资产；服务端架构覆盖、层次及源码映射、业务操作与架构无图阅读等专业要求保留在架构参考。Skill 可按任务引用架构规范，但一般图示任务不因此强制产生完整服务端基线。架构/研发职责按需调用操作 Skill，不改变判断和交接责任。

旧规范保留原专业章节和迁出章节的锚点跳转，旧示例保留锚点跳转到 Skill 唯一示例。更新现行使用方及能力清单，生成宿主入口；历史记录保留原事实。保留其他迭代未提交修改，不在本轮交付边界内安装或发布。

独立架构只读评审：`boundary_review`（gpt-6.1-terra / xhigh）核对总纲、归属、现行规范、能力及生成器，建议上述拆分；提醒额外检查锚点、技能路由、独立调用，以及避免把语法/渲染通过当成专业正确。本结论针对设计，不是实现评审。
