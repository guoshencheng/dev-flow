# 六职责原生子 Agent 自动注册验收用例

## 本次验收什么

验证现有 install 命令一次注册六个原生职责，重复安装、升级、检查和卸载保持一致，保护同名用户角色、用户改动及无关配置。依据用户原始要求、设计 v3 和计划 v1；[技术验证](technical-checks.md)维护检查映射。实现只提供执行入口，不决定预期。

用例作者为独立 acceptance（sol medium），主 Agent 整合写入；已独立 Review并执行通过，见[验收结果](acceptance-result.md)。主 Agent 将并发预期明确为锁占用时拒绝第二个操作、解除后可重试，不要求自动排队；这承接设计的非阻塞操作锁。

## 场景与预期

| 用例 | 场景及前置 | 操作 | 必需预期 |
| --- | --- | --- | --- |
| TC-01 | 干净隔离用户目录首次安装 | install，读回，check | 无需逐个配置即有完整六角色、有效正文/资源及归属，check 通过 |
| TC-02 | 已注册安装和旧版无注册安装两种状态 | 各再次 install/check | 不重复创建角色，旧版直接获得完整注册，无手工步骤 |
| TC-03 | 已有注册；新缓存根含空格、括号、#、> | 升级，提取所有本地链接并解码，check | 正文/引用更新至已验证新缓存，资源真实存在，无旧根或开发仓库引用 |
| TC-04 | 正常状态分别制造缺失、改动、缓存/归属异常、未启用及实际版本错配/缺失 | 各 check；缺失角色另 install/check | 每种异常失败并指出原因；缺失可修复，用户改动不可自动覆盖；实际版本/来源错误时 install 不提交角色 |
| TC-05 | 非受管同名文件、链接、目录，或不同文件声明同一职责名 | 各 install | 预检明确拒绝且指出位置，插件 CLI 变更前停止，已有内容不变 |
| TC-06 | 外来配置含注释、正文、数组/表等伪 name；另备真实冲突与不确定配置 | 各 install/提取名称 | 伪字段不冲突，真实冲突拒绝，无法可靠识别时保守报错且保留文件 |
| TC-07 | 新安装及已有安装；记录操作前角色/归属/仓库记录字节 | 注入角色、状态、记录写入错误，移除故障重试 | 文件事务回滚存在性及字节，明确失败和 install 恢复入口，重试通过；不推定旧缓存可用 |
| TC-08 | 预检后提交前暂停；两个进程共享临时用户目录 | 修改目标再继续；独立进程争用锁再重试 | 修改不被覆盖；占用时第二进程明确失败，释放后可重试，最终状态完整，无混合注册 |
| TC-09 | 正常注册及缺失一受管角色两种状态，有无关配置 | remove，读回 | 正常清理归属明确且未修改的角色/记录；缺失可清理，无关内容不变，插件/来源按既有规则移除 |
| TC-10 | 受管角色修改、链接替换、来源错误，另备无归属记录状态 | 各 remove | 修改/链接/来源错误在 CLI 移除前拒绝；无归属不删个人角色 |
| TC-11 | 已注册且保存原字节 | 注入卸载文件删除错误；恢复后 install/check | 明确失败，文件回滚，不宣称 CLI 回退，重试恢复 |
| TC-12 | 自定义 CODEX_HOME 含空格，默认目录及个人配置快照 | 自定义目录 install/check/remove | 只管理指定目录；默认目录、无关角色、config、AGENTS 原字节不变，角色不固定模型/推理 |
| TC-13 | 完整隔离验收及授权有效，候选已固定 | 主 Agent 真实 install/check；验收者独立读回 | 实际启用版本、来源、源码/缓存及六角色一致，全部本地引用有效 |
| TC-14 | 实际注册完成，新进程/刷新宿主 | 核对发现，按原生角色名派发最小只读任务 | 有实际名称识别、指定角色调用及元数据证据；通用 spawn 和文件存在不能替代；不可用保持未执行并记录刷新方法 |
| TC-15 | 官方文档和宿主版本可定位 | 核对页面/清单/安装回调、Hooks、setup | 未核实自动入口时明确说明脚本安装边界，不将脚本结果外推页面支持 |
| TC-16 | 旧基线与最终候选在同条件夹具可运行 | 同一六角色断言旧新对照；生成/构建核验 | 旧因角色缺失而失败，新通过；三清单 0.6.0、六职责/16 Skills、总纲 0.32 一致 |

## 覆盖边界与待明确事项

隔离目录与模拟 CLI 证明文件生命周期，真实安装和原生发现/派发分别留证。Windows、断电/SIGKILL、多文件与外部 CLI 的跨事务、旧缓存保留及 Kimi 安装不在承诺范围。TC-14 不能由入口不可用改为通过。正式执行依赖独立用例 Review 与固定候选；必需检查未执行或失败，所属 TC 不通过。
