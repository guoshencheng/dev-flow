# 可复用 React 设计稿模板

本次依据用户已明确的结构与模拟范围直接实施，沿用 `codex/modular-ui-design` 分支及此前指导改动，基线为 `42f0089`。主 Agent 顺序承担实现、产品/视觉检查与工程自查，不登记独立职责评审。源码归视觉 Skill 的 assets，复制工具归该 Skill 的 scripts；项目副本独立维护。

## 设计与产出

- 独立 Vite + React + TypeScript 工程，锁定依赖，可完整复制到项目稳定目录，不引用插件运行路径或自有 npm 包。
- 以虚构的 B 端订单任务展示桌面和移动视图，使用 antd 基础组件；两端组合独立，领域组件、数据与主题共用。C 端项目按已有 shadcn/ui 体系替换视图，不将产品定位和屏幕端固定绑定。
- 一个总览页整合页面、组件与设计规范；独立路由和总览使用同一注册表与实际模块。移动 iframe 保持声明的内部屏幕宽高，外层控制尺寸/显示缩放，不模拟设备操作。
- 设计规范使用独立 Markdown，规范展示读取原文；色彩、字号、间距与主题从真实 Token 模块读取。页面规格、组件契约及迭代增量示例分别维护。
- 初始化命令只在空目标创建源码副本，保留已有工程；不自动安装依赖、改写项目指引或复制依赖缓存。

## 实施与检查

1. 建立工程、模块/路由、虚构场景、总览、屏幕容器和独立规范，提供源码与启动/扩展说明。
2. 实现初始化工具，验证新目录、已有内容拒绝覆盖、重复初始化与路径/符号链接边界。
3. 在隔离项目复制后执行锁文件安装、严格类型检查和构建；启动该副本，实际检查总览、两端视图、组件/规范、尺寸切换、状态与详情弹层边界。
4. 自查共享来源、独立路由和总览一致性、移动内部视口以及生产构建路由；修复后定向复验。更新职责现状和引用，纳入 Git 打包清单并刷新安装插件，核验源码与缓存一致。

## 验收预期

目标副本能独立安装、启动和构建；总览能访问各端页面、组件与规范，独立入口显示同一成果。尺寸修改实际改变 iframe 内部视口，内容内部滚动且弹层留在相同浏览上下文；状态切换可复现加载/空/错误/正常，示例搜索与详情有反馈。规范修改反映到展示，主题和组件没有平行的现行副本；再次初始化不覆盖项目定制。浏览器证据与复制回归证明工具范围，不登记真实生产项目或真实移动设备兼容已验证。
