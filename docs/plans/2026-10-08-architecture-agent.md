# 架构 Agent 首版建设计划

日期：2026-10-08。任务来源：用户要求先建设架构职责，以整洁架构细化拆分，并在研发结束后复核代码业务、维护当前架构/目录模块分工和提出改进建议。

1. 增加无固定模型的 `dev_architecture` 原生设置和 `dev-architecture` Skill，将整洁架构、系统模块地图、设计契约、复盘演进及项目资产维护拆为按需方法。
2. 提供现状/模块地图、变化设计和代码复盘模板，复用共享 Vite 文档预览和 Git 管理。
3. 在总纲和执行协议加入架构的过程参与、交付核验与研发后的复盘；保持用户确认设计/用例、AI 复核实现计划后自主实施。
4. 核验 Skill/TOML/引用、临时和真实全局安装，使用隔离案例检查架构行为，分别记录静态、专业行为、原生派发和真实项目状态。验证后提交本地 Git。
