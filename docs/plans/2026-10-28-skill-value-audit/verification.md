# Skill 价值清理验证

## 候选与独立 Review

对象为当前工作区的两项 Skill 撤销、方法迁移及引用更新；先前技术图示和插件完整性迭代的未提交内容是共有基线，不登记成本轮成果。

架构职责执行者 `boundary_review`（gpt-6.1-terra / xhigh）独立审查设计，提出对照不足、路由与兼容映射缺口；主 Agent 补充边界实验、局部职责加载模拟与迁移清单后，原评审者定向复验关闭设计阻断。实现后其独立只读 Review 检查两份正文、旧路径六个章节跳转、研发/验收引用、能力清单和生成入口，需求符合性与实现质量在静态范围内通过。审阅不证明真实宿主自动发现、实际安装或真实业务表现。

## 核验结果

- 诊断、回归参考与迁移前工作区文件逐字对比，仅调整必要相对链接；两份旧参考的六个原章节锚点逐项指向新正文。
- 受影响现行文档的 138 个相对文件/标题锚点通过；顺手修正研发现状中原有代码收尾锚点。`git diff --check` 及 `python3 scripts/sync_host_agents.py --check` 通过，报告六职责、16 项候选 Skill。
- 将当前受管源码、两份新增研发参考、先前技术图示候选及本轮文档复制进独立临时 Git 仓库并纳管，在该隔离候选运行 `python3 -m unittest discover -s tests -p 'test_plugin_installation.py'`：21 项通过。该快照同时含本轮开始时已有插件完整性修改；与源码/缓存一致性和真实宿主安装是不同结论。
- 对 README、能力清单、研发提示词、插件文档，以及 Codex/Kimi 两份研发生成物，将本次具体改动在内存中逆向还原后计算哈希，与 Progress 所记本轮修改前的六个 SHA-256 全部一致；保留技术图示技能及对应角色路由。这一核对覆盖这些共享文件，不扩大到工作区所有文件。
- 三组主对照和两组边界对照见[盘点](audit.md)：有无 Skill 的单次样例均能完成主要诊断或回归目标，但存在提示偏置、Skill 组用 mock、旧版不可运行和仅函数级验证等限制，不能推广为复杂任务等价。

## 交付限制

真实安装脚本按 Git 管理的文件打包，本次提交须纳入新增研发参考；正式发行前按 0.x 不兼容变化升级 minor、同步清单/宿主入口并重新验证、安装及检查。旧 `$defect-diagnosis` 与 `$regression-verification` 在当前源码候选中不再可发现；旧参考路径保留跳转，旧 `SKILL.md` 外链不兼容。明确加载研发职责时的局部模拟找到新参考；普通自然语言请求是否自动加载职责、新会话宿主发现、真实项目应用及安装均未验证。
